01 Getting Started

New user path

Welcome to CabEngine Pro

CabEngine Pro is an advanced cabinet software integration suite for high-fidelity 3D cabinet design and manufacturing. Use the cabinet configurator API and embeddable 3D planner to streamline your workflow from first layout to workshop-ready files.

Best starting route
  • Create a project with room dimensions and client context.
  • Define board, finish, hardware and material defaults.
  • Open 3D Studio and build the first cabinet layout.
Core outputs
  • Bill of materials and cost breakdown.
  • Cut plan and wall elevation reports.
  • DXF, CNC-ready files and quote-ready PDF packs.

07 Cabinet Configurator API & Embeddable 3D Planner

08 FAQ & Troubleshooting

Support

Common questions

Why are my backsplash tiles looking stretched?

Verify the physical tile dimensions in the accessory library. Realistic textures require accurate dimensions to calculate real-world scaling.

How do I jump directly to BOM from the dashboard?

Open the project action menu and choose Reports & BOM. You can also pin reports as a shortcut for active production jobs.

Does advanced mode affect BOM precision?

No. Advanced mode only changes how you manually enter and control geometry. Engineering logic and cost calculations remain accurate.

How do I get technical support?

For complex engineering queries or hardware integration fixes, contact support with your project reference and screenshots.
